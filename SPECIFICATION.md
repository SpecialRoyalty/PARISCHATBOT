# Cahier des charges implémenté

- Rôles : utilisateur, trusted, admin, super admin.
- Panels privés par rôle.
- Pronostics avec image, catégories boutons, vote privé, score exact.
- Match nul toujours présent.
- Message de groupe fusionné : match + stats + bouton.
- Mise à jour du message à chaque vote.
- Suppression du message au début du match.
- Clôture par admin/super admin après fin approximative.
- Classement par taux, participations, scores exacts.
- Invitations uniques en privé.
- Suggestions privées.
- Trusted : proposer match + ajouter mot interdit + /ban /supprime.
- Admin : création, clôture, mots interdits, règles, ouverture/fermeture.
- Super admin : rôles, broadcast, start texte/photo, hashes, logs, info.
- Modération : liens ban, mots interdits, commandes, médias hash, notifications entrée/sortie.
